# SolitaireXP

Clone de Paciência Klondike estilo Windows 3.1 — HTML/CSS/JS vanilla + GSAP, instalável como PWA.

## Rodar localmente

```bash
http-server -p 8080 -c-1
```

Abra [http://127.0.0.1:8080](http://127.0.0.1:8080).

## Assets

Sprites Kenney em `.resources/` (gitignored). Cópias usadas pelo jogo em `assets/cards/`.

# SolitaireXP

Clone de Paciência Klondike estilo Windows 3.1 — HTML/CSS/JS vanilla + GSAP, instalável como PWA.

## Rodar localmente

```bash
http-server -p 8080 -c-1
```

Abra [http://127.0.0.1:8080](http://127.0.0.1:8080).

## Assets

Cartas: pacote "Casino" em `.resources/Casino/Cards/` (gitignored, fonte em alta
resolução), por **Moxica (playground)** — licença proprietária em
